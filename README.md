Personal Portfolio Website 🌐
Welcome to the Personal Portfolio Website project!
This was my very first project, where I took my first step into web development. The goal was to create a simple yet effective portfolio to showcase my skills, projects, and interests using only HTML and CSS.

✨ Project Overview
The Personal Portfolio Website serves as a digital introduction to who I am, highlighting:

My personal bio and interests.
A list of projects and accomplishments.
My contact information for potential collaborations.
This project was an exciting starting point that allowed me to learn and practice fundamental web development skills.

🛠️ Technologies Used
HTML: For structuring the content of the website.
CSS: To style and visually enhance the website's appearance.
🌟 Key Features
A clean and simple layout that focuses on content clarity.
Navigation bar for easy access to different sections.
A Projects section showcasing a list of early projects.
Contact section with my email and links to social media profiles.
Fully responsive design for both desktop and mobile devices.
🎓 What I Learned
🖼️ HTML Fundamentals
Structuring web pages with semantic elements like <header>, <footer>, and <section>.
Using links (<a>), images (<img>), and lists (<ul>/<ol>) effectively.
🎨 CSS Basics
Styling text, images, and layout using properties like color, font-family, and margin/padding.
Learned to create a responsive design using media queries.
Experimented with hover effects and transitions for better interactivity.
🌐 Web Development Workflow
Understood the importance of organizing HTML and CSS files.
Learned how to test and debug a website across different devices and browsers.
📌 Challenges Faced
Alignment Issues: It took time to understand how to properly align elements using CSS box model.
Responsive Design: Initially struggled with media queries but eventually learned how to make the site mobile-friendly.
🚀 Reflections
This project was a foundational milestone in my journey as a web developer. It taught me the importance of planning, practice, and attention to detail in creating websites. As my very first project, it holds a special place in my portfolio as a testament to my growth and learning.
